# Проект: сайт turkishgoturkey.club

Сайт для изучения турецкого языка с морской свинкой Анатолием. Генерируется Hugo, хостится на GitHub Pages.

## Деплой

Сайт деплоится **автоматически** через GitHub Actions при любом пуше в `main`.

- Workflow: `.github/workflows/hugo.yml`
- После `git push` деплой занимает ~40 секунд
- Проверить статус: `gh run list --limit 3`
- **Не нужно** запускать `upload.sh` — он устарел (rsync на EC2)

## Структура контента

- `content/времена/` — статьи про времена (настоящее, прошедшее и т.д.)
- `content/необходимая теория/` — базовая грамматика (падежи, гармония гласных и т.д.)
- `content/дополнительная теория/` — продвинутая грамматика
- `content/слова/` — словарные списки (без примеров свинки)

## Featured images (иллюстрации к статьям)

Каждая грамматическая статья должна иметь `featured_image` в frontmatter:
```toml
featured_image = 'slug.webp'
```

Файл кладётся в `themes/my/static/`. Стиль: детализированная cartoon-иллюстрация морской свинки Анатолия в тематической сцене, kawaii + аниме, насыщенные цвета, без текста в изображении.

Для генерации новых изображений — скрипт с готовыми промптами для всех статей:
```bash
pip install google-genai
GEMINI_API_KEY=... python3 scripts/generate_images.py
```
Ключ бесплатно на https://aistudio.google.com/apikey. Скрипт использует **Imagen 3** (google-genai), конвертирует в WebP через `cwebp -q 85`, добавляет `featured_image` в frontmatter. Все промпты хранятся в `scripts/generate_images.py`.

Изображения хранятся в WebP (оптимизированы через `cwebp -q 85`). Исходные PNG после конвертации удаляются.

## Шаблон грамматической статьи

Каждая грамматическая статья должна содержать (в таком порядке):

1. **Краткое описание** конструкции: что означает, когда использовать (1–3 предложения)
2. **Формулу образования** с `**жирным**` выделением аффиксов
3. **Примеры предложений** с переводом
4. **Блок `{{< svin >}}`** в конце — 3 предложения из жизни свинки Анатолия
5. **Квиз** — 5 вопросов в TOML frontmatter (секция `[quiz]`)

### Шаблон блока свинки
```
{{< svin >}}
Я свинка Анатолий и говорю: «**[Turkish sentence].**» — «[Русский перевод]».  
Потом добавляю: «**[Turkish sentence].**» — «[Русский перевод]».  
И уточняю: «**[Turkish sentence].**» — «[Русский перевод]».
{{< /svin >}}
```

Примеры должны быть **разнообразными** из жизни морской свинки: бегать в колесе, сидеть в клетке, пищать, есть капусту/сено/петрушку/яблоко/морковку/огурец, общаться с другими свинками, бояться, радоваться.

### Шаблон квиза (в TOML frontmatter, перед закрывающим `+++`)
```toml
[quiz]
  [[quiz.questions]]
    question = "Вопрос на русском?"
    type = "single-choice"
    [[quiz.questions.answers]]
      text = "Правильный вариант"
      correct = true
    [[quiz.questions.answers]]
      text = "Неправильный вариант"
      correct = false
    [[quiz.questions.answers]]
      text = "Ещё неправильный"
      correct = false
```

Правила квиза:
- 5 вопросов на статью
- Тип: `"single-choice"`, 3 варианта (1 правильный, 2 неправильных)
- Вопросы на русском, варианты ответов — турецкие предложения/формы
- Разнообразные формулировки: «выберите правильную форму», «переведите», «как правильно сказать»

## Оглавление (TOC)

На мобильных экранах TOC показывается **над** контентом (Bootstrap `order-first`), на десктопе — справа (4 колонки). Реализовано через Bootstrap grid в `themes/my/layouts/page.html`, float не используется.
