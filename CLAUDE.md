# Проект: сайт turkishgoturkey.club

Сайт для изучения турецкого языка с морской свинкой Анатолием. Генерируется Hugo, хостится на GitHub Pages.

## Деплой

Сайт деплоится **автоматически** через GitHub Actions при любом пуше в `main`.

- Workflow: `.github/workflows/hugo.yml`
- После `git push` деплой занимает ~40 секунд
- Проверить статус: `gh run list --limit 3`
- **Не нужно** запускать `upload.sh` — он устарел (rsync на EC2)

## Структура контента

- `content/времена/` — статьи про времена (настоящее, прошедшее и т.д.)
- `content/необходимая теория/` — базовая грамматика (падежи, гармония гласных и т.д.)
- `content/дополнительная теория/` — продвинутая грамматика
- `content/слова/` — словарные списки (без примеров свинки)

## Шаблон грамматической статьи

Каждая грамматическая статья должна содержать:
1. Краткое описание конструкции (что означает, когда использовать)
2. Формулу образования с **жирным** выделением аффиксов
3. Примеры предложений
4. Блок `{{< svin >}}` в конце — 3 предложения по теме из жизни свинки Анатолия

### Шаблон блока свинки
```
{{< svin >}}
Я свинка Анатолий и говорю: «**[Turkish sentence].**» — «[Русский перевод]».  
Потом добавляю: «**[Turkish sentence].**» — «[Русский перевод]».  
И уточняю: «**[Turkish sentence].**» — «[Русский перевод]».
{{< /svin >}}
```

Примеры должны быть **разнообразными** из жизни морской свинки: бегать в колесе, сидеть в клетке, пищать, есть капусту/сено/петрушку/яблоко/морковку/огурец, общаться с другими свинками, бояться, радоваться.

## Оглавление (TOC)

На мобильных экранах TOC показывается **над** контентом (Bootstrap `order-first`), на десктопе — справа (4 колонки). Реализовано через Bootstrap grid в `themes/my/layouts/page.html`, float не используется.
